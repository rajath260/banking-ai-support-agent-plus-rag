# Debit Card FAQ (Fictional Demo Policy)

This document contains fictional policy examples for learning and testing. It is not an actual bank policy.

## How can I block a lost debit card?

A customer who has lost a debit card should block it immediately using the bank's official mobile application or customer support channel. The customer should review recent transactions and report any transaction they do not recognize.

## How can I request a replacement card?

After blocking the lost card, the customer can request a replacement through the official banking channel. The replacement process and delivery timeline depend on the bank's actual policy.
